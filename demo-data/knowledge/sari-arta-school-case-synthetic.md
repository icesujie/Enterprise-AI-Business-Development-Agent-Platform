# School Central Kitchen Case — Synthetic Demo

This is a fictional portfolio case created only for product demonstration.

A multi-campus education operator requested an early concept for a central kitchen serving approximately 3,000 meals per day. The synthetic scope includes receiving, dry and cold storage, separated preparation zones, cooking, portioning, dispatch, washing, ventilation coordination, and staff workflow review.

The example is not proof of a completed Sari Arta project and contains no real customer information.
